# पीपा परंपरा — Pipa Parampara

A Hindi-first, source-based community archive for the Pipa Kshatriya Darji / Pipa
Kshatriya Rajput community: history, the 33 Bhaktamal episodes, the verse corpus,
the 204-village directory, pilgrimage sites, organisations, and documents.

Everything is hand-written static HTML generated by a build script. No framework,
no runtime dependencies, no external CDN.

## Build

```bash
node build.mjs
```

Output goes to `dist/` (about 4 MB). Serve it with any static server:

```bash
cd dist && python3 -m http.server 4321
```

`build.mjs` wipes and recreates `dist/` on every run, so never edit files there.

## Verify

```bash
npm install            # playwright-core only — the single dev dependency
npm run build
npm run serve          # in another terminal
npm run verify         # console errors, broken links, overflow, search, filters, no-JS
npm run audit          # contrast, tap targets, heading outline, weight, CLS
npm run og             # 16 social cards → assets/og/ (needs the server running)
```

`tools/verify.mjs` drives real Chrome and checks every page at 1280 px and at
320/390/768/1180 px, plus the search dialog, the verse filter, the village table,
preference persistence, print styles and the site with JavaScript off. It exits
non-zero on the first failure set. Nothing in it ships to production.

## Conventions

- **Hindi first.** English appears only where it is a proper noun or a citation.
  `en.html` is written by hand; no page is machine-translated.
- **Every claim carries a source and a confidence badge** — 🟢 प्रमाणित / 🟡 परंपरा /
  🔵 स्थानीय / ⚪ मतभेद. Competing narratives sit side by side; the site does not
  adjudicate the caste-boundary debate.
- **Privacy.** Only published office-bearers and office contacts appear. No household
  or personal member directory, ever.
- **Works without JavaScript.** Tables, verses and text are static HTML; JS only adds
  search, filtering, tabs, the quiz and the theme controls.
- **Numerals follow the reader.** Western digits (`204`) are the default; the `Aa`
  dialog can switch every count to Devanagari (`२०४`) and the choice is remembered.
  The build emits both forms inside a `<span class="num">`, so the switch is pure CSS
  and nothing re-renders or flashes. Source files stay in Devanagari; `build.mjs`
  derives the Latin run, and `<head>`/JSON-LD/sitemaps always get plain digits.

## Reading features

- **Search** — `/` or `⌘K` opens a dialog scoped to all / verses / villages / pages.
  Works from any page; `khoj.html` also accepts `?q=`. Search normalises Devanagari
  (combining marks, spelling variants) so "सुई" and "सुंई" match the same verse.
  Results are indexed in Western digits and re-rendered through the reader's numeral
  setting, so a snippet matches the page it links to.
- **Search in Latin script** — every entry also carries romanised spellings built at
  build time ("समदड़ी" → `samadari`, `samdari`, `smdari`), so a phone keyboard typing
  "samdari", "pachpadra" or "pipaji" finds the same pages. A vowel-skeleton fallback
  covers spellings the index did not anticipate.
- **Verse permalinks** — each verse is `vani.html#pad-N`, with a `§` button that copies
  the exact URL and highlights the verse. The search index has one entry per verse,
  so a query lands on the verse rather than the whole collection.
- **Preferences** — the `Aa` button sets theme (paper / night / soft / contrast),
  font, text size, measure, motion, numerals and language. Stored in `localStorage`,
  applied before first paint, so there is no flash.
- **Book mode** — `granth.html` is the same corpus laid out as a book, with a
  sticky TOC, reading-progress bar and print styles.
- **Social cards** — every page ships its own `og:image` (`assets/og/<slug>.png`),
  rendered from the built `<h1>` and description by `npm run og`. The shared
  `assets/og.png` is the fallback for a fresh clone.
- **Verse posters** — the `पोस्टर` button draws a 1080×1350 keepsake card on a
  canvas (seal, verse, source, URL). Phones get the native share sheet; desktop
  downloads the PNG. `WhatsApp` in the citation row opens `wa.me` with the page
  title and URL, because that is where this audience actually shares.
- **Translation** — the language select lives in the `Aa` dialog and does nothing
  until the reader picks a language. It then writes the `googtrans` cookie and
  reloads once, which is the only path that reliably lands on the first try; the
  page scroll position is restored, the site's own banner reports the state
  (`loading` → `done` → `failed` with a retry), and Google's own toolbar is hidden.
  "मूल हिन्दी" clears the cookie and returns to the original. Selecting a second
  language re-runs the same handshake.
- **Print / cite / share** — every page's citation row carries "उद्धरण कॉपी करें",
  "यह पृष्ठ छापें" and "साझा करें" (Web Share API, clipboard fallback).

## Machine-readable surface

- `sitemap.xml` — 16 URLs, `lastmod` from the build date.
- `robots.txt` — allows everyone, disallows `/404.html`, explicit rules for GPTBot,
  ClaudeBot, Google-Extended, PerplexityBot and friends.
- `llms.txt` / `llms-full.txt` — a curated map of the archive for language models.
- `feed.xml` — Atom feed of the dated events on `samachar.html`.
- `manifest.webmanifest` + icons — installable, offline-tolerant shell.
- Per-page JSON-LD: `WebSite` + `Organization` + `WebPage` + `BreadcrumbList`
  everywhere, plus `Person` (pipaji), `Book` (granth), `FAQPage` (prashnottari),
  `ItemList` of `TouristAttraction` (tirth), `HinduTemple` + `Event` (samdari),
  `ItemList` of `Event` (samachar), `Article` (en), `SearchResultsPage` (khoj).

## Deploy

`dist/` is plain static files. Drag it to Netlify, Cloudflare Pages, GitHub Pages, or
any bucket.

`SITE.url` in `src/layout.mjs` and `SITE_URL` in `build.mjs` must both point at the
real origin (`https://pipaparampara.in` by default, used for canonical URLs, JSON-LD
`@id`s and the sitemap). Change both if the domain changes.

No build step runs on the host, so there is nothing to configure: no Node on the
server, no environment variables, no secrets. The only network call in the whole
site is the optional Google Translate widget.

## What is deliberately not here

- The Sagwara household and mobile directory, and the 13-patron phone list.
- The `research/` working folder itself. It holds the household contact directory,
  the patron phone list and OCR of in-copyright print books, so it stays out of the
  public repo. Every source the site relies on is cited on the page that uses it.
- Any claim known to be unverified — those sit in `research/` with a note, or on the
  page inside a ⚪ मतभेद card, never as fact.
- Analytics, trackers, cookies, ads, comment systems, or any server-side code.
